# Wedzway - Destination Wedding Platform

A comprehensive destination wedding platform connecting couples with verified wedding service providers globally.

---

## 🚨 Having Issues? Quick Fixes

### Issue 1: Blank Page
**Error:** `process is not defined`  
**Fix:** You're running Vite instead of Next.js  
**Solution:** [QUICK_FIX.md](./QUICK_FIX.md)

### Issue 2: Module Not Found
**Error:** `Can't resolve '@/components'`  
**Fix:** You're in the wrong directory  
**Solution:** [QUICK_DIRECTORY_FIX.md](./QUICK_DIRECTORY_FIX.md)

## ⚡ Quick Start

```bash
# 1. Make sure you're in the directory with package.json
pwd
ls -la    # Should see: app/, components/, package.json

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev

# 4. Open browser
# http://localhost:3000

# 5. Login with password
# wedzway2025
```
